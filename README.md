# Beijing Air Quality Analysis

## 📌 Project Overview

This project focuses on analyzing air quality data from Beijing to understand pollution levels, identify trends, and explore the relationship between different air-quality parameters.

The project includes data cleaning, exploratory data analysis, visualization, and interpretation of important patterns in the dataset.

## 🎯 Objectives

* Clean and prepare the air quality dataset.
* Handle missing and inconsistent values.
* Analyze air pollution trends over time.
* Explore the relationship between air-quality variables.
* Identify important patterns and observations.
* Present the findings through meaningful visualizations.

## 📂 Dataset

The dataset contains air-quality observations from Beijing.

### Dataset Source

[Beijing PM2.5 Dataset – UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/501/beijing+pm2+5+data)

The dataset includes air-quality and weather-related attributes such as:

* PM2.5
* PM10
* SO2
* NO2
* CO
* O3
* Temperature
* Pressure
* Dew Point
* Wind Speed
* Wind Direction
* Rainfall
* Snowfall

## 🔄 Project Workflow

### 1. Data Collection

The Beijing air quality dataset was collected from the UCI Machine Learning Repository.

### 2. Data Cleaning

The following data-preprocessing activities were performed:

* Imported the dataset into Python.
* Checked the number of rows and columns.
* Inspected data types.
* Identified missing values.
* Handled null values.
* Checked duplicate records.
* Converted date-related columns into the required format.
* Prepared the dataset for analysis.

### 3. Exploratory Data Analysis

The dataset was explored using:

* Descriptive statistics
* Mean, minimum, and maximum values
* Monthly and yearly analysis
* Pollution-level comparisons
* Correlation analysis
* Trend analysis

### 4. Data Visualization

Different charts were created to understand the data, including:

* Line charts
* Bar charts
* Histograms
* Box plots
* Heatmaps
* Scatter plots

## 📊 Key Analysis Areas

* PM2.5 pollution trend over time
* Comparison of major air pollutants
* Monthly pollution patterns
* Yearly air-quality variations
* Relationship between weather conditions and pollution
* Correlation between air-quality parameters
